# Security Policy

Please do not publish active exploit details, secrets, or sensitive deployment information in a public issue.

For security reports, describe the affected component, expected impact, minimal reproduction details, and any proposed mitigation. Avoid including credentials or private data.

This repository is a reference implementation and does not by itself provide production identity, network isolation, secret management, sandboxing, or infrastructure hardening. Deployments must add controls appropriate to their environment and threat model.
